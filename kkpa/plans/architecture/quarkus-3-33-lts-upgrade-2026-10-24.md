## Context

- Repo: `jbh-personal-finance`, a Quarkus multi-module Maven monolith. Java 21.
- Quarkus is pinned in the root `pom.xml`, property `<quarkus.version>3.18.4</quarkus.version>`.
  It feeds `quarkus-bom` and `quarkus-maven-plugin` (both group `io.quarkus.platform`).
- 3.18 is end-of-life. 3.33 LTS has community support until 25 Mar 2027. Newer minor versions
  exist, but the user chose the LTS line. Check <https://quarkus.io/releases> for the newest
  3.33.x patch (a `3.33.x.y` micro-patch may exist for LTS) and use it.
- Extensions in use: `quarkus-arc`, `quarkus-rest`, `quarkus-rest-jackson`,
  `quarkus-smallrye-openapi`, `quarkus-smallrye-health`, `quarkus-hibernate-orm-panache`,
  `quarkus-hibernate-validator`, `quarkus-jdbc-postgresql`, `quarkus-liquibase`,
  `quarkus-mailer`, `quarkus-qute`, `quarkus-junit5`, `quarkus-junit5-mockito`, plus
  `io.quarkiverse.hibernatetypes:quarkus-hibernate-types` `2.2.0` (not managed by the BOM).
- Config is in 4 files: `jbh-finance/jbh-finance-infra/src/main/resources/application.properties`,
  `jbh-preferences/jbh-preferences-infra/src/main/resources/application.properties`,
  `jbh-notification/jbh-notification-infra/src/main/resources/application.properties`,
  `jbh-z-assembly/src/main/resources/application.properties`.
  They use named datasources and named persistence units (`finance`, `preferences`,
  `notifications`), `quarkus.index-dependency.*`, and `quarkus.arc.*`.
- The repo uses JPMS (`module-info.java` in 10 modules) and Jandex. Read
  `docs/guides/jandex-and-modules.md` before you touch module config.
- The jump crosses 15 minor versions. The risk is in breaking changes, not in the version bump.
- Scaling rule from `.claude/CLAUDE.md` still holds: the app runs with 2 or more instances.
  This upgrade must not add in-JVM state.
- Do the work on a new branch. `main` is protected in this repo: push the branch and open a PR.

### 1. Collect the breaking changes
<!-- Execution order: 1. Prerequisites: none. Goals: G2, G3. -->

- Open the Quarkus migration guides on the GitHub wiki
  (<https://github.com/quarkusio/quarkus/wiki/Migration-Guides>). Read each guide from
  `3.19` up to `3.33`. Use Context7 (`/websites/quarkus_io_guides`) for the update guide
  <https://quarkus.io/guides/update-quarkus> if the wiki is hard to read.
- Write a short checklist in the Execution Notes section of this plan. Keep only items that
  touch this repo: the extensions in "Context", `quarkus.*` properties, JPMS/Jandex, Liquibase,
  named persistence units, Qute, mailer, OpenAPI, JUnit/Mockito test support.
- Pay special attention to: Hibernate ORM major version changes, Hibernate Validator,
  Liquibase version, `quarkus-rest` behavior changes, Jackson, and Java baseline.
- Expected outcome: a written list of the changes that apply. Sections 2 to 5 use it.

### 2. Bump the version and check dependency versions
<!-- Execution order: 2. Prerequisites: section 1. Goals: G1, G2. -->

- In root `pom.xml`, change `<quarkus.version>3.18.4</quarkus.version>` to the 3.33.x patch
  chosen in "Context". Change nothing else in that property block yet.
- Check `io.quarkiverse.hibernatetypes:quarkus-hibernate-types` (`2.2.0`, in
  `jbh-finance-infra/pom.xml`, `jbh-notification-infra/pom.xml`,
  `jbh-preferences-infra/pom.xml`). Find the release that supports Quarkus 3.33 (Maven Central
  or <https://github.com/quarkiverse/quarkus-hibernate-types>). If the BOM now manages it,
  remove the explicit `<version>`. If the Hibernate ORM major version changed in Quarkus, the
  extension may be incompatible: then replace its usage per its docs, and note it in the
  Execution Notes.
- Check `testcontainers.version` (`1.19.5`), `mockito.version` (`5.10.0`), and the JaCoCo,
  PMD, SpotBugs plugin versions in root `pom.xml`. Raise one only if section 1 or the Quarkus
  BOM requires it (for example a Mockito version that the Quarkus test extension needs).
- Search for other hard-coded Quarkus versions: `/usr/bin/grep -rn "3\.18" --include=pom.xml .`

- Expected outcome: `pom.xml` files name only versions that work with 3.33.
